# eternalsmile layout/style

everything webpage related to eternalsmile, used as a basis for local html chapter releases, comic fury referencing, newgrounds, and itch.io

#### wishlist of features i want
- swapping page versions
- changing theme of entire page with a dropdown menu
- page navigation with keyboard
- a "comic has been read" state that changes the cover page on the index page
- save and load bookmarking system
- a keyboard shortcut or button to enable zooming in on a page
- somehow learn how to make a script that can automatically compile an archive by just feeding it pages, with options to change default page resolution

#### 2000 x 3500 page sizes are the main consideration by default.
- drop the pages in named (1r-21r).png in assets/pagetray alongside the .html files
- for old pages place them in assets/pagetray/old as (1t-21t).png or (1s-21s).png
- to get the dev image from popping up and disappearing add either add "off" class to the sticker div, remove "boo long" from classes, or just delete the dev.png from assets/pagetray
- mini-mode is enabled by adding mini as a class to the body
